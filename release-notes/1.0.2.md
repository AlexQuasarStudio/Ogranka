# Огранка 1.0.2

## Что нового

- Добавлен режим «Рамка» (клавиша B): левая кнопка мыши больше не вращает
  модель, а тянет прямоугольник и выделяет попавшие в него элементы.
  Вращение в этом режиме — правой кнопкой, зум — колесом, выход — B или Esc.
- Рамка работает для граней, вершин, рёбер и сечений. Тип элементов
  переключается в списке «Выделять» или клавишей V. Shift добавляет,
  Ctrl/Cmd убирает.
- Выделение хранится отдельно для каждого типа: можно выделить грани,
  переключиться на рёбра или сечения и добавить их, не теряя предыдущее.
- Сводка выделения показывает число элементов, площадь и долю поверхности
  для граней и число вершин. Кнопка «Копировать» кладёт сводку в буфер.
- «Инверсия» (Shift+I), «+1 грань» и «−1 грань» (Shift+] и Shift+[)
  помогают быстро править выделение.
- «OBJ выделения» сохраняет только выбранные грани, переиндексируя вершины.
- Новое окно вьюпорта наследует включённую рамку и текущий тип выделения.
- Обновлены справка и обучающий тур.

## Установка

- macOS: распаковать `Ogranka-macos-1.0.2.zip`, запустить `Огранка.app`.
  При первом запуске может понадобиться «Открыть» через контекстное меню.
- Windows: запустить `Ogranka-windows-1.0.2.exe`.
  SmartScreen может предупредить, потому что файл не подписан платным сертификатом.
- Linux: сделать `Ogranka-linux-1.0.2.AppImage` исполняемым и запустить.
  Для arm64 используйте файл с суффиксом `arm64`.
