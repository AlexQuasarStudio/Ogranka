# Огранка 1.0.3

## Что нового

- Рамка теперь показывает выделение в реальном времени: элементы
  подсвечиваются прямо во время протягивания прямоугольника, не дожидаясь
  отпускания мыши. Обычное выделение — жёлтое, добавление (Shift) — зелёное,
  вычитание (Ctrl/Cmd) — красное; в подписи рамки видно количество.
- Превью работает для граней, вершин, рёбер и сечений.
- Статистика выделения обновляется при переключении активного вьюпорта:
  площадь, доля поверхности и число вершин считаются по активному окну.
- Переключение вьюпорта больше не сбрасывает выделение: первый клик по
  неактивному окну только активирует его.
- Esc в режиме рамки одновременно выключает рамку и снимает выделение.
  В полноэкранном виде Esc больше не выходит из него, а снимает выделение;
  выход из полноэкранного вида — кнопка «⤢» или F.
- Обновлены справка и обучающий тур.

## Установка

- macOS: распаковать `Ogranka-macos-1.0.3.zip`, запустить `Огранка.app`.
  При первом запуске может понадобиться «Открыть» через контекстное меню.
- Windows: запустить `Ogranka-windows-1.0.3.exe`.
  SmartScreen может предупредить, потому что файл не подписан платным сертификатом.
- Linux: сделать `Ogranka-linux-1.0.3.AppImage` исполняемым и запустить.
  Для arm64 используйте файл с суффиксом `arm64`.
