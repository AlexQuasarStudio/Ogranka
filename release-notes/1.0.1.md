# Огранка 1.0.1

## Что нового

- Версия приложения теперь задаётся в одном месте — `app/config.py`.
- В окне «Что нового» показываются патчноуты из описания GitHub-релиза.
- Добавлена проверка обновлений: в шапке появляется «Доступно обновление».
- Обновление скачивается и устанавливается прямо в приложении; после установки
  приложение перезапускается само.
- Linux поставляется только как AppImage; tar-архив убран.
- Исправлены мелочи в интерфейсе и сборке.
- Добавлены CI, E2E-smoke-тест и MIT-лицензия.
- Добавлен бенчмарк реальных моделей и автоматическая сборка релизов по тегу.
- История изменений доступна в приложении постоянно, независимо от наличия обновления.
- Автообновление учитывает номер сборки; в интерфейсе используется «сборка».
- Лофт сглаживает каждое кольцо рядом Фурье перед сшиванием.
- Windows-версия открывается в собственном окне WebView2, а не в браузере.
- Добавлена Linux-сборка: `Ogranka-linux-1.0.1.AppImage` с иконкой.
- При запуске загружаются все сохранённые модели, а не только последний прогон.
- Сброс вида в вьюпорте теперь плавно возвращает камеру к модели.
- В шапке вместо «новая сборка/версия» показывается «Доступно обновление»;
  после перезапуска появляется угловая плашка об установленной сборке, а при
  запуске с доступным обновлением справа снизу показывается тост.
- Обратная связь через GitHub: форма открывает issue в браузере
  с уже заполненным текстом, можно приложить файлы; во вкладке
  «Проблемы GitHub» видны issues с лейблами.
- Скриншоты: кнопка в шапке вьюпорта с меню «Вьюпорта» и «Приложения»;
  кроп с затемнением, пометки с перемещением, ресайзом, поворотом и сменой
  цвета; Enter сохраняет PNG через системный диалог.

## Установка

- macOS: распаковать `Ogranka-macos-1.0.1.zip`, запустить `Огранка.app`.
  При первом запуске может понадобиться «Открыть» через контекстное меню.
- Windows: запустить `Ogranka-windows-1.0.1.exe`.
  SmartScreen может предупредить, потому что файл не подписан платным сертификатом.
