# Огранка 1.1.0

Большое обновление производительности, надёжности и интерфейса.

## Быстрее

- Конвейер с настройками по умолчанию (r8 и r80, Фурье и «соседи»,
  минимальные многогранники) работает в 20–30 раз быстрее: шесть демо-тел —
  около 9 с вместо 4 минут, три реальные модели по ~2000 вершин — около 11 с
  вместо 4 минут.
- «Соседи» больше не пересчитывают скользящее среднее сотни тысяч раз:
  все окна считаются один раз через накопленные суммы.
- Сечения, площади, слияние компланарных граней и привязка вершин к
  плоскостям переписаны на векторных операциях NumPy.
- Живой предпросмотр отвечает в 3–5 раз быстрее, «6 уровней упрощения» —
  в 7 раз.
- 3D-окна рисуют кадр только при изменениях: в простое приложение не
  нагружает видеокарту и батарею. Оси рисуются в том же WebGL-контексте,
  поэтому окон можно открыть больше без потери контекстов.
- Топология модели считается один раз при загрузке, а не при каждом клике
  выделения.
- Дельта-обновления собираются в 7–8 раз быстрее.

## Меньше

- В сборку больше не попадают OpenBLAS, gfortran и quadmath из SciPy
  (около 30 МБ): Qhull получает заглушку LAPACK, которая ему нужна только
  для импорта. Linux-сборка стала меньше на четверть, Windows — заметно
  легче; на macOS эти библиотеки и раньше не использовались.
- Из сборки исключены неиспользуемые части NumPy и стандартной библиотеки.

## Исправления

- Минимальные многогранники могли получаться разными и неверными: ядро
  fast-simplification хранит сетку в глобальных переменных, а варианты
  считались параллельно. Вызовы теперь сериализованы.
- Метрики минимальных многогранников учитывали сечения неверно: вершины,
  лежащие ровно на плоскости сечения, отбрасывались. Из-за этого крайние
  слои пропускались, а часть сечений обрезалась и давала случайный d_max.
- «Соседи» сглаживают и зону между последним и первым минимумом —
  раньше этот участок оставался зашумлённым.
- Загрузка файлов с кириллицей в имени больше не падает.
- Убранные окна освобождают WebGL-контекст и останавливают отрисовку.
- Свежая установка больше не показывает тост «Обновление установлено».
- «Выделить всё» работает в активном окне, а не всегда в первом.

## Интерфейс

- Новый дизайн: карточки параметров, чипы для уровней шума и методов,
  сгруппированная панель инструментов, закреплённая кнопка запуска,
  аккуратные таблицы и бейджи качества.
- Светлая и тёмная тема; по умолчанию — как в системе (кнопка в шапке).
- Подсказка в пустых окнах, плотные оболочки рисуются тонкими рёбрами.
- Окна справки и настроек держат фокус клавиатуры и возвращают его.
- Адаптивная раскладка для узких окон.

## Безопасность

- Локальный сервер принимает запросы только с 127.0.0.1/localhost и
  требует служебный заголовок для изменяющих запросов: сторонний сайт в
  браузере больше не может очистить кеш или запустить расчёт.

## Для разработчиков

- `app.py` разделён на модули: `server`, `jobs`, `releases`, `native`,
  `paths`, `versioning`; общий код конвейера и предпросмотра —
  `core/variants.py`.
- Один PyInstaller-спек `ogranka.spec` для всех систем.
- `--self-test` проверяет собранное приложение; CI запускает его для
  macOS, Windows, Linux и AppImage до публикации.
- Тесты: 64 (было 42), проверка Ruff в CI.

## Установка

- macOS: распаковать `Ogranka-macos-1.1.0.zip`, запустить `Огранка.app`.
  При первом запуске может понадобиться «Открыть» через контекстное меню.
- Windows: запустить `Ogranka-windows-1.1.0.exe`.
  SmartScreen может предупредить, потому что файл не подписан платным сертификатом.
- Linux: сделать `Ogranka-linux-1.1.0.AppImage` исполняемым и запустить.
  Для arm64 используйте файл с суффиксом `arm64`.
