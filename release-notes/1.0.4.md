# Огранка 1.0.4

## Критические исправления

- Обновление больше не блокируется повреждённой дельтой: при несовпадении
  SHA256 приложение удаляет дельту и автоматически скачивает полный архив.
  Сообщение «Обновление повреждено» появляется только после неудачи полной
  загрузки.
- Закрытие окна во время расчёта больше не теряет готовые результаты:
  завершённые модели сохраняются сразу, а рабочий поток дожидается окончания
  расчёта.
- После смены модели восстанавливаются точные идентификаторы выделения.
  Экспорт OBJ, рост, сужение, инверсия и статистика продолжают работать при
  переключении активного вьюпорта.
- macOS-обновление безопаснее меняет бандл и перезапускает приложение через
  `open -n`. При неудачной замене старая копия больше не выдаётся за успешно
  установленную.

## Важные исправления

- Рамка выбирает грань при любом её видимом попадании в прямоугольник.
- В режимах «каркас» и «рёбра» выбранные грани подсвечиваются жёлтым overlay.
- Esc закрывает окна справки, истории, обратной связи и обновления; в
  полноэкранном вьюпорте снимает выделение и выходит из него.
- Очистка кеша блокируется во время расчёта.
- Запросы проверки обновлений сериализованы; отметка «обновление установлено»
  не теряется между запросами.
- Кеш минимальных многогранников защищён от одновременного доступа.

## Установка

- macOS: распаковать `Ogranka-macos-1.0.4.zip`, запустить `Огранка.app`.
  При первом запуске может понадобиться «Открыть» через контекстное меню.
- Windows: запустить `Ogranka-windows-1.0.4.exe`.
  SmartScreen может предупредить, потому что файл не подписан платным сертификатом.
- Linux: сделать `Ogranka-linux-1.0.4.AppImage` исполняемым и запустить.
  Для arm64 используйте файл с суффиксом `arm64`.
