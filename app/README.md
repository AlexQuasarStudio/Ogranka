# Огранка

Локальное приложение: загружает одну или много моделей, режет их
горизонтальными сечениями, добавляет шум, сглаживает, восстанавливает форму,
строит минимальные многогранники и показывает результат в двух--шести 3D-вьюпортах
с метриками и оценкой качества.

## Два способа запуска

**Готовое приложение (macOS, arm64).** `Огранка.app` в корне проекта — двойной клик
открывает отдельное окно программы (не браузер). Если macOS не пускает файл,
нажмите по нему правой кнопкой → «Открыть» (подпись не нотариальная).
Размер около 1.2 ГБ: внутри Python, numpy, scipy и движок окна; обычной почтой
такой файл не уйдёт — нужна ссылка на диск.

**Windows.** Соберите на Windows командой `build_windows.bat` (нужен Python 3.9+
и WebView2 — в Windows 10/11 он обычно уже стоит). Получится
`dist\Ogranka.exe` — один файл, запуск двойным кликом.

**Из исходников.** Нужны Python 3.9+, numpy, scipy и fast-simplification; Open3D не нужен.
Без fast-simplification работает собственная QEM-декцимация:

```bash
python3 -m pip install -r requirements.txt
python3 app.py
```

Из исходников окно открывает pywebview; если пакет не установлен, откроется браузер.
Другой порт: `--port 8770`. Без окна: `--no-window` (тогда браузер).

## Что на входе

- **Демо-тела**: октаэдр, икосаэдр, додекаэдр, бриллиант, куб и правильная восьмиугольная призма.
- **Несколько файлов** OBJ или TXT (`x y z`) — выбираются сразу.
- **Папка** с моделями, включая подпапки: берутся все `.obj` и `.txt`.

Файлы обрабатываются пакетом: каждая модель проходит конвейер целиком.

## Что задаётся

- Шум: r8 (0.008), r80 (0.08) и свои уровни через запятую — несколько за раз.
- Сглаживание: Фурье + МНК (M гармоник), «соседи» (окно k), без сглаживания.
- Восстановление: полуплоскости (для реальных огранок) или максимумы.
- Минимальный многогранник: автоматический режим с ручными параметрами —
  допуск по площади (%) и угол слияния граней (°).
- 6 уровней упрощения: отдельная кнопка строит минимальные многогранники
  при 100, 70, 50, 35, 25 и 15 % оставленных треугольников.
- Сетка: число слоёв и направлений.

## Справка

Кнопка «?» в правом верхнем углу открывает справку: пороги качества,
выделение, окна и камера, форматы файлов, шум и методы. У элементов
интерфейса есть всплывающие подсказки.

## Что показывает

- **От 2 до 6 окон**: кнопки «+ окно» и «− окно»; в каждом окне свой вариант
  для сравнения. Вращение мышью, зум колесом, сдвиг правой кнопкой.
- **Общая камера**: вращение и зум одного окна повторяют все остальные
  (галочка «общая камера»). Кнопка «⛶» разворачивает окно на весь экран.
- **Синхронное выделение**: выбранная грань или вершина подсвечивается во всех
  окнах; если разбиение другое, подсвечивается ближайшая грань.
- **Выделение как в Blender**: клик — одна грань (или вершина в режиме
  «вершины»), Shift — путь по соседним граням/вершинам от последней выбранной,
  Ctrl/Cmd — добавить или убрать одну, выделение сразу видно во всех окнах,
  клик по пустому месту — снять, `A` — выделить всё, `Alt+A` — снять.
  Счётчик выделенного выводится под вьюпортами.
- Раскраска: однотонная, грани разными цветами, по площади грани, каркас,
  рёбра, вершины. Выделять можно грани или вершины — переключатель «выделять»
  работает в любом режиме отображения.
- **Оценка качества**: хорошо / средне / плохо по RMSE (порог 0.03 и 0.12).
  Оценка стоит в таблице вариантов, у каждого вьюпорта и в пакетной таблице.
- **Пакетная таблица**: по каждой модели — лучший вариант, MSE, RMSE, d_max
  и качество; клик по строке открывает модель.
- Таблица метрик вариантов: MSE, RMSE, d_max, вершины, грани, точки.
- Строка сравнения: разницы метрик между выбранными вариантами.
- Экспорт: OBJ выбранной модели, PNG вьюпорта, CSV всех метрик.

## Метрики

Сравнение по опорной функции: для каждого слоя восстановленное сечение
проецируется на те же направления, что и эталон; считаются MSE, RMSE и
максимальное отклонение d_max. Качество: хорошо при RMSE < 0.006,
средне при RMSE < 0.03, иначе плохо.

## Скорость

Демо-тела — доли секунды. Реальная модель (552 вершины, 60 слоёв × 720
направлений, два уровня шума, оба метода, минимальные многогранники) —
около 4 секунд.

## Где лежат данные

- Сборка: `~/Library/Application Support/ShapePipeline` (macOS),
  `%APPDATA%/ShapePipeline` (Windows), `~/.local/share/shape-pipeline` (Linux).
- Исходники: папки `uploads/` и `runs/` рядом с `app.py`.

## Структура

```
app.py              сервер и конвейер (API + раздача интерфейса)
core/pipeline.py    геометрия, шум, сглаживание, восстановление, метрики
static/             интерфейс (index.html, app.js, style.css)
static/vendor/      three.js и OrbitControls (офлайн)
dist/ShapePipeline  однофайловая сборка (macOS arm64)
```

## Ограничения

- Тела должны быть выпуклыми.
- «Соседи» используют фиксированное окно k; адаптивный подбор по зонам
  из отчёта не перенесён.
- Однофайловая сборка платформозависима: собранный файл работает на macOS
  arm64. Для Windows нужна своя сборка тем же PyInstaller.
- 403 МБ — обычная почта такой файл не примет; удобнее ссылка на диск.
