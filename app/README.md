# Огранка

Локальное приложение: загружает одну или много моделей, режет их
горизонтальными сечениями, добавляет шум, сглаживает, восстанавливает форму,
строит минимальные многогранники и показывает результат в двух--шести 3D-вьюпортах
с метриками и оценкой качества.

Создатель: Дьяченко Алексей, 5 курс, механико-математический факультет МГУ.
Научный руководитель: Валединский Владимир Дмитриевич.

## Два способа запуска

**Готовое приложение (macOS, arm64).** `Огранка.app` в корне проекта — двойной клик
открывает отдельное окно программы (не браузер). Если macOS не пускает файл,
нажмите по нему правой кнопкой → «Открыть» (подпись не нотариальная).
Размер около 57 МБ: внутри Python, numpy, Qhull и движок окна; обычной почтой
такой файл не уйдёт — нужна ссылка на диск.

**Windows.** `Ogranka.exe` открывает собственное окно через WebView2 (Edge),
без адресной строки браузера. Если WebView2 недоступен, приложение пробует
режим приложения Edge/Chrome, затем браузер по умолчанию. Сборка на Windows:
`build_windows.bat` (Python 3.9+), результат — `dist\Ogranka.exe`. Версия
и номер сборки берутся из `config.py`; скрипт сам обновляет `version_info.txt`.

**Linux.** `Ogranka-linux-*.AppImage` — один файл с иконкой и записью меню:
`chmod +x Ogranka-linux-*.AppImage` и запустить. В собранной версии AppImage
обновляется из окна «Обновление»: приложение скачивает новый образ, заменяет
текущий файл и перезапускается. Tar-архив больше не публикуется.

**Из исходников.** Нужны Python 3.9+, numpy, scipy, fast-simplification и certifi (для HTTPS-проверки обновлений); Open3D не нужен. В готовой сборке полного SciPy нет — только маленькое Qhull-расширение.
Без fast-simplification минимальный многогранник не строится:

```bash
python3 -m pip install -r requirements.txt
python3 app.py
```

Из исходников на macOS и Windows окно открывает pywebview (на Windows —
WebView2); если бэкенд недоступен, используется Edge/Chrome или браузер.
Другой порт: `--port 8770`. Без окна: `--no-window` (тогда браузер).

## Что на входе

- **Демо-тела**: октаэдр, икосаэдр, додекаэдр, бриллиант, куб и правильная восьмиугольная призма.
- **Несколько файлов** OBJ или TXT (`x y z`) — выбираются сразу.
- **Папка** с моделями, включая подпапки: берутся все `.obj` и `.txt`.

Файлы обрабатываются пакетом: каждая модель проходит конвейер целиком.

## Что задаётся

- Шум: r8 (0.008), r80 (0.08) и свои уровни через запятую — несколько за раз.
- Сглаживание: Фурье + МНК (M гармоник), «соседи» (окно k), без сглаживания.
- Восстановление: полуплоскости (для реальных огранок) или максимумы.
- Минимальный многогранник: автоматический режим с ручными параметрами —
  допуск по площади (%) и угол слияния граней (°).
- 6 уровней упрощения: отдельная кнопка строит минимальные многогранники
  при 100, 70, 50, 35, 25 и 15 % оставленных треугольников.
- Сетка: число слоёв и направлений.

## Справка

Кнопка «?» в правом верхнем углу открывает справку: пороги качества,
выделение, окна и камера, форматы файлов, шум и методы. У элементов
интерфейса есть всплывающие подсказки.

## Что показывает

- **От 2 до 6 окон**: кнопки «+ окно» и «− окно»; в каждом окне свой вариант
  для сравнения. Вращение мышью, зум колесом, сдвиг правой кнопкой.
- **Общая камера**: вращение и зум одного окна повторяют все остальные
  (галочка «общая камера»). Кнопка «⛶» разворачивает вьюпорт на всю область;
  высоту можно менять разделителем, в том числе в развёрнутом режиме.
- **Сброс вида**: кнопка «Сбросить вид» и клавиша `G` плавно возвращают камеру к модели.
- **Синхронное выделение**: выбранная грань, вершина, сечение или ребро
  подсвечивается во всех окнах; если разбиение другое, подсвечиваются
  покрывающие грани и их вершины.
- **Выделение как в Blender**: клик — один элемент, Shift — путь по соседям
  от последней выбранной, Ctrl/Cmd — добавить или убрать, клик по пустому
  месту — снять; при смене режима выделение не сбрасывается. Для вершин
  работает логика родитель-ребёнок (подсвечиваются родительские грани и их
  вершины), для рёбер — путь по общим вершинам. `L` — только выделенное,
  `A` — выделить всё, `Alt+A` — снять. Счётчик выделенного выводится под
  вьюпортами; `V` переключает грани → вершины → рёбра → сечения.
  `,` и `.` переключают модель в активном окне, `[` и `]` — вариант обработки.
- **Живой предпросмотр**: ползунки шума и доли оставленных треугольников
  обновляют активное окно без запуска конвейера. При шуме 0 сглаживание
  не применяется — форма совпадает с точной. Предпросмотр не попадает
  в таблицу и сохраняется только после запуска конвейера.
- **История прогонов**: при запуске загружаются все сохранённые модели;
  новый запуск добавляет модели в список, старые остаются доступными до
  «Очистить кеш»; одинаковые имена различаются временем и коротким кодом прогона.
- **Обратная связь**: форма открывает GitHub в браузере с уже заполненным
  текстом; можно приложить файлы, а вкладка «Проблемы GitHub» показывает
  issues с лейблами.
- **Разные модели во вьюпортах**: у каждого окна есть свой выбор модели.
  Верхний список «модель» задаёт модель сразу для всех окон, а выбор в шапке
  окна меняет только это окно; `,` и `.` переключают модель активного окна,
  `[` и `]` — вариант обработки.
- Раскраска: однотонная, грани разными цветами, по площади грани, каркас,
  рёбра, вершины. Выделять можно грани, вершины, рёбра или сечения —
  переключатель «выделять» работает в любом режиме отображения.
  Ортогональный вид включается галочкой или клавишей `P`.
- **Оценка качества**: хорошо / средне / плохо по средней ошибке (MSE/RMSE) и максимальному отклонению dmax.
  Оценка стоит в таблице вариантов, у каждого вьюпорта и в пакетной таблице.
- **Пакетная таблица**: по каждой модели — лучший вариант, MSE, RMSE, d_max
  и качество; клик по строке открывает модель.
- Таблица метрик вариантов: MSE, RMSE, d_max, вершины, грани, точки.
- Строка сравнения: разницы метрик между выбранными вариантами.
- Экспорт: OBJ выбранной модели, PNG вьюпорта или приложения, CSV всех метрик.

## Метрики

Сравнение по опорной функции: для каждого слоя восстановленное сечение
проецируется на те же направления, что и эталон; считаются MSE, RMSE и
максимальное отклонение d_max. Качество: хорошо при RMSE ≤ 0.03 и dmax ≤ 0.15,
средне при RMSE ≤ 0.12 и dmax ≤ 0.30, иначе плохо.

## Скорость

Демо-тела — доли секунды. Реальная модель (552 вершины, 60 слоёв × 720
направлений, два уровня шума, оба метода, минимальные многогранники) —
около 4 секунд.

## Где лежат данные

- Сборка: `~/Library/Application Support/ShapePipeline` (macOS),
  `%APPDATA%/ShapePipeline` (Windows), `~/.local/share/shape-pipeline` (Linux).
- Исходники: папки `uploads/` и `runs/` рядом с `app.py`.

## Структура

```
app.py              сервер и конвейер (API + раздача интерфейса)
updater.py          скачивание, установка и перезапуск
core/pipeline.py    геометрия, шум, сглаживание, восстановление, метрики
static/             интерфейс (index.html, app.js, style.css)
static/vendor/      three.js и OrbitControls (офлайн)
dist/ShapePipeline  однофайловая сборка (macOS arm64)
```

## Обновления

При запуске приложение один раз проверяет последний релиз в GitHub
(`AlexQuasarStudio/Ogranka`). Если версия или сборка новее, в шапке появляется
«Доступно обновление». В окне обновления показывается
«Установить и перезапустить»: приложение скачивает файл для текущей ОС,
устанавливает его и самостоятельно перезапускается.

Автоустановка работает в собранной версии, если папка приложения доступна для
записи. На macOS приложение не должно быть запущено из временной папки
App Translocation; на Windows и Linux нужны права на замену файлов приложения.
Если автоустановка недоступна, остаётся скачать файл вручную или открыть
страницу релиза. Проверить вручную можно в «О программе» → «Проверить
обновления».

## Ограничения

- Тела должны быть выпуклыми.
- «Соседи» используют фиксированное окно k; адаптивный подбор по зонам
  из отчёта не перенесён.
- Однофайловая сборка платформозависима: собранный файл работает на macOS
  arm64. Для Windows нужна своя сборка тем же PyInstaller.
- 57 МБ — обычная почта такой файл не примет; удобнее ссылка на диск.
