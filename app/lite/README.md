# Огранка Lite

Тонкая сборка без встроенного Python и зависимостей. Использует системный Python 3.10+ с `numpy`, `scipy` и `fast-simplification`.

## macOS

```bash
bash lite/build_macos.sh
```

Результат — `../Огранка Lite.app` размером около 2 МБ. При запуске лаунчер ищет подходящий Python в стандартных местах; если зависимостей нет, показывает команду для их установки.

## Windows

Запускать `OgrankaLite.cmd` рядом с каталогом `app`, либо перенести `cmd` в папку, где лежат `app.py`, `core/`, `static/` и модули приложения. Используется `py -3` или `python`; проверяются те же зависимости.

## Ограничения

- Версии Python и wheel-пакетов должны быть совместимы.
- Нет автоматической установки зависимостей и индикатора загрузки: при отсутствии пакетов лаунчер сообщает команду.
- Для полностью автономной работы используйте основную сборку с встроенными зависимостями.
